=== ANARCHY SURVIVAL MODE ===
2b2tmuseum features a vanilla survival experience in an infinite world that never resets. There are no gameplay rules, no moderators, no operators, PvP is enabled, and cheats are allowed (encouraged). The server promotes an environment where players are allowed to explore, build, steal, betray, fight, and grief with no limits in 2b2tmuseum's massive world.

There are some modifications made to the vanilla survival gamemode designed to protect you, the archived locations, and the server itself that you can read about below:

  • Obfuscation of Chunk Age
    It is harder for game mods to systematically distinguish the difference between newly generated and previously generated chunks, making it harder for players to follow "trails" of visited chunks, and impossible for automated bots to map or follow these trails.

  • Entity Spawning Optimisations
    The server runs a generous 24 chunk render and simulation distance, and without optimisation, mobs would spawn too far away from the player and quickly fill up the mob cap with mobs that will never be seen. To prevent this, the server will block the spawning of a percentage of mobs that naturally spawn too far away from the player, so that these mobs can respawn closer to the player. These changes will not affect mobs that have already spawned, and will not affect mob farms as long as there is a player nearby to keep it activated.

  • Survival Integrity Protections
    To prevent blocks and items uploaded onto the server from 2b2t world-downloads from influencing the survival gamemode, the server will track and validate all items legitimately obtained on the server. The server will automatically remove or prevent access to unverifiable items and storages.

  • Server-side Freecam
    It is possible to temporarily switch out of survival mode using the /freecam command. You cannot progress the game or modify the world while in Freecam mode. Upon switching back into survival mode, you are kicked from the server and your player data is restored exactly how it was before you left Survival mode. There are many protections in place to prevent players from using this feature to escape certain deaths, find player bases, keep chunks loaded indefinitely, or otherwise gain a significant unfair advantage.

  • Warp Protection
    Although it is possible to visit the warp locations in survival mode by manually travelling to them, the server will passively prevent players from changing the blocks or hurting non-player entities in these areas. Hostile mobs will not spawn in these areas, and existing hostile mobs that attempt to hurt you will be automatically removed. Melee PvP will continue to be enabled between players who are in Survival mode, however, it will be impossible to pick up any loot in these areas.

  • Phantoms
    Phantoms are currently disabled, however they may be re-enabled in the future and tweaked to allow spawning in a non-aggressive manner.

  • Custom Server List Messages
    It is possible to write your own server list message. A server list message appears in the Minecraft client's multiplayer menu in yellow on 2b2tmuseum's server list entry. You can visit our store to purchase a permanent custom server list message for $6 CAD.

  • Chat and Death Messages
    • Chat is re-worked to allow greentext by placing ">" as the very first character of your message.
    • Whispering has been re-worked to allow easier access to reply commands.
    • The server allows you to /ignore certain players who you don't want to see messages from.
    • The server allows you to /togglechat to hide chat messages altogether.
