2b2tmuseum features a vanilla survival experience in an infinite world that never resets. There are no gameplay rules, PvP is enabled, and cheats are allowed (encouraged).
There are some modifications made to the vanilla survival gamemode designed to protect you, the warps, and the server itself that you can read about below:
  • Obfuscation of Chunk Age
    It is harder for game mods to systematically distinguish the difference between newly generated and previously generated chunks, making it harder for players to follow "trails" of visited chunks, and impossible for automated bots to map or follow these trails.
  • Entity Spawning Optimisations
    The server will attempt to spawn mobs closer to the player. As the server runs a 24 chunk render and simulation distance, without optimisation, mobs would spawn too far away from the player and quickly fill up the mob cap. To prevent this, the server will block the spawning of a percentage of mobs that naturally spawn too far away from the player, so that they can respawn closer.
  • Survival Integrity Protections
    To prevent blocks and items uploaded onto the server from 2b2t world-downloads from influencing the survival gamemode, the server will track and validate legitimately obtained items, and the server will automatically remove or prevent access to unverifiable items and storages.
  • Server-side Freecam
    It is possible to switch in and out of survival mode using the /freecam command. You cannot progress the game or modify the world while in Freecam mode. Upon switching back into survival mode, you are kicked from the server and your player data is restored exactly how it was before you left Survival mode. There are protections in place to prevent abuse of this command, and are actively being tweaked to achieve the best balance and fairness.
  • Warp Protection
    Although it is possible to visit the warp locations in survival mode by manually travelling to them, it is not possible for players to change the blocks or hurt non-player entities in these areas. Hostile mobs will not spawn in these areas. Melee PvP will continue to be enabled between players who are in Survival mode, however, it will be impossible to pick up any loot in these areas.
  • Phantoms
    Phantoms are currently disabled, however they may be re-enabled in the future and tweaked to allow spawning in a non-aggressive manner.
  • Custom Server List Messages
    It is possible to write your own server list message. A server list message appears in the Minecraft client's multiplayer menu in yellow on 2b2tmuseum's server list entry. You can visit our store to purchase a permanent custom server list message for $6 CAD.
  • Chat and Death Messages
    • Chat is re-worked to allow greentext by placing ">" as the very first character of your message.
    • Whispering has been re-worked to allow easier access to reply commands.
    • The server allows you to /ignore certain players who you don't want to see messages from.
    • The server allows you to /togglechat to hide chat messages all together.
